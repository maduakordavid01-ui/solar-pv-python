# 5 MWp Solar PV Plant: Electrical Design (Montpellier, France)
Preliminary design of a 5 MWp ground-mounted, grid-connected PV plant.

| Folder | Content |
|---|---|
| `01_SLD_Drawing/` | Single-line diagram (Revit): strings, inverters, MV transformer, grid connection |
| `02_Energy_Analysis/` | Energy yield workbook (Excel) and PVGIS data for Montpellier (CSV) |
| `03_Project_Report/` | Design report: site, sizing, string calculations, energy yield |
| `04_References/` | Datasheets: JA Solar JAM72S30-550/MR module, Sungrow SG250HX-20 inverter |

**Key figures:** 9,152 modules · 26 modules/string · 16 × 250 kW inverters · 5.03 MWp DC / 4 MW AC · DC/AC 1.26

**Python version:** the same plant is rebuilt and simulated in [`01_my_pv_simulation.ipynb`](../01_my_pv_simulation.ipynb).
